Smart Distance Detector

Project Overview

The Smart Distance Detector is a beginner-friendly electronics project designed to detect the distance of an object using an ultrasonic sensor.

Components Used

- Arduino Uno
- Ultrasonic sensor (HC-SR04)
- Buzzer
- LED
- Resistor
- Jumper wires

Working Principle

The ultrasonic sensor measures the distance between the sensor and an object. The Arduino processes the sensor readings and activates the buzzer when an object comes within the programmed distance.
